## 范围

本轮只处理**可复现、影响明确、改动可回滚**的缺陷：契约导出物过期、文档与实现不一致、前端已知的运行时错误与契约漂移。每个修复单独提交，不推送远端。

结构性风险（全局调度锁串行、容量全表扫描、备份排他锁、Runner 本地证据增长、无自动化测试等）不在本轮直接改动；它们需要架构决策、压测或新增测试授权，单列在“不修复项”并以证据说明。

2. 契约导出幂等：`python -m eyes.contracts.schema` 与 `python -m eyes.contracts.agent_protocol` 重新生成，与已提交文件逐字节一致。

6. 汇总命令、原始输出与限制，写入 `docs/fix-verification-20261017.md`，提交后交用户审阅。
