# Eyes 前端质量记录

更新日期：2026-10-03。

## 首轮品质迭代结果

以 Awwwards、Webby Awards、FWA 作品的完成度作为长期目标，首轮使用 Eyes 当时的暖灰、纸白、朱红、细边框与本地字体，完成核心页面和公共交互的优化，并通过真实控制 API 检查可独立于 Agent 执行的流程。其后的纯白主题和 shadcn 改造记录见本文末尾与 [控制台文档](frontend.md)。

用户明确要求“先完成前端，暂缓真实 Agent 联调”。本轮没有启动 Runner、Scheduler 或真实 Agent。没有填写虚构输出、事件或评分；截图中的排队记录来自实际创建的实验。

**整体获奖品质门槛仍未通过。** 真实执行审阅、评分引用定位、复杂数据表现、性能实测与交叉任务复查还缺运行证据，因此不发布加权自评分，也不把静态检查计为端到端验收。

## 实现范围

| 页面或组件 | 本轮改变 | 用户收益 |
| --- | --- | --- |
| 实验工作台 | 未连接首屏聚焦连接；已连接显示实际记录；搜索/筛选/分页保存在 URL；创建前摘要 | 找到下一步操作，返回后继续原任务 |
| 执行审阅 | 独立路由、本页用例导航、历史尝试、事件列表与详情、评分引用导航 | 留出足够阅读空间，能够分享带分页与选中项的审阅链接 |
| 事件详情 | 接收次序、来源、生产者序号、发生/接收时间、Span 与父 Span | 核对已采集事实，缺失字段显示未提供 |
| JSON | 完整内容复制与反馈、长内容折叠、匹配行搜索 | 审阅长内容，复制完整记录 |
| 结果对比 | 数据集/评分摘要/观测声明/执行参数核对、原始差异筛选、审阅链接、最新输出展开 | 先核对条件，继续查看对应执行；保留汇总与最新尝试的区别 |
| 目录与运行状态 | 按连接与数据状态组织主操作，Runner 空状态提供接入入口 | 减少重复占位和无效操作 |
| 公共交互 | 模态滚动锁定、固定标题与提交区、移动导航焦点恢复、可访问名称、按页加载代码 | 长表单与不同屏幕下可持续操作 |

审阅链接的 `page` 为从零开始的用例页；`attempt`、`view`、`events`、`manifests`、`event`、`manifest` 保存当前审阅位置。实验详情的 `q`、`section`、`page` 保存列表状态。进入用例的路由状态保留实验与实验列表的返回条件。刷新需要重新认证；手动分享链接不携带令牌或原列表路由状态。

## 自检与修复循环

| 发现的问题 | 修改 | 复查证据 |
| --- | --- | --- |
| 未连接首屏被指标和筛选挤占 | 连接入口与工作流程进入首屏 | 桌面与手机截图，主操作可见 |
| 多标签弹窗限制证据阅读 | 独立执行审阅空间 | 实际排队用例可打开，输入/预期及未执行状态正确 |
| 对比时配置变化不突出 | 顶部配置核对与差异数量 | 同测试集/评分器的 300s 与 600s 超时标为一项不同 |
| 手机连接按钮缺可访问名称 | 加入连接设置名称 | 手机浏览器按名称打开对话框 |
| 长表单标题或提交入口移出画面 | 固定标题与操作区，限制背景滚动 | 平板与 Safari 长表单滚动后仍可关闭与提交 |
| 切换审阅标签丢失返回筛选 | 修改查询参数时保留路由状态 | 搜索 task-summary，进入审阅并切换评分标签，再返回仍保留搜索 |
| 小桌面侧栏出现横向滚动 | 收窄时隐藏副标题并约束水平溢出 | 1024px 侧栏 clientWidth 与 scrollWidth 均为 199px |
| 对比差异筛选为空缺恢复操作 | 增加清除筛选 | 选择执行状态不同得到空状态，清除后恢复两条记录 |
| 新建实验后其他页面缓存未同步 | 同时失效实验列表、对比选择与运行状态查询 | 静态检查通过；后续创建行为需继续复查 |

## 已验证范围

环境：macOS Apple Silicon，Codex 内置浏览器；Safari 使用原生界面补查。Vite 开发服务为 `127.0.0.1:5173`，API 为 `127.0.0.1:8000`。独立 PostgreSQL 17 容器映射到 `127.0.0.1:55432`，应用 `0001_control_plane` 迁移，数据保存在本轮隔离项目 Eyes UI Review。

### 真实控制 API 与浏览器操作

- 数据库就绪和前端代理就绪请求实际返回 200。
- 无效令牌返回 401，并显示错误；只读令牌发布目标返回 403，表单内容保留。
- 管理令牌发布一个 HTTP 待联调配置、导入两条 JSONL 任务、发布一个 rules 评分配置；评分器实现摘要取自当前真实源码。
- 实际创建两次实验，分别固定 300s 与 600s 超时；后端保存排队工作，未领取、未执行、未评分。
- 实验详情、审阅页与对比页显示排队、零次尝试、尚无评分、未开始采集，未把缺失评分显示为通过。
- 检查目录、运行状态、指南和比较的已连接空状态；检查筛选无结果及恢复操作。
- 手机导航打开后焦点进入侧栏；Escape 关闭后恢复到导航按钮。关闭侧栏存在 inert 属性，主体不横向溢出。
- Safari 实际认证成功，目录打开正常；原生对话框、Escape 关闭与固定标题/提交区的滚动行为已目视检查。

### 响应式与静态检查

执行审阅检查 390、700、768、1024、1440、1920px 的主体宽度与布局；目录/指南/运行状态检查平板，工作台检查手机和桌面，对比检查手机、平板与桌面。700px 为中间尺寸测量；并非所有业务状态在所有断点都已覆盖。宽表格和代码采用局部滚动。

最终执行：

```sh
npm --prefix frontend run lint
npm --prefix frontend run format:check
npm --prefix frontend run build
```

全部通过。build 包含 TypeScript。当前主 JS 312.68 kB / gzip 99.85 kB，页面主体分块约 5–19 kB（Vite 输出，十进制单位）。这证明构建体积，未证明实际首屏速度、布局稳定性或大数据性能。最终首页浏览器 warn/error 记录为空。

未新增或修改测试、fixtures、mocks、自动化 snapshots；本文截图是实际界面的人工视觉验收材料。

## 保留的质量门槛与差距

沿用计划中的内部标准：视觉/品牌 25%、任务效率 25%、原创交互 20%、状态可信度 15%、响应式/无障碍/性能 15%；总分目标 90，各维度至少 85。所有分数须有证据，未验证项不算通过。该标准为 Eyes 自定，实际奖项由外部评审决定。

| 维度 | 当前证据 | 剩余差距 |
| --- | --- | --- |
| 视觉与一致性 | 核心页面、目录与空状态目视检查 | 复杂事件与评分内容尚未经过实际页面审阅；参照作品的逐项交叉评审待补 |
| 任务效率 | 配置发布→入队→用例审阅，筛选返回和恢复已检查 | 失败定位→评分依据→事件/产物引用的完整任务未验证 |
| 原创交互 | 独立审阅、事件选择与证据定位已有实现 | 实际父子关系的探索与长输出差异阅读仍需提升并验证 |
| 状态可信度 | 401/403、空数据、排队与未执行状态已检查 | 证据不足、晚到清单、未知结果和评分错误的实际交互未验证 |
| 响应式与工程质量 | 主要断点、Safari 局部流程、lint/typecheck/build 通过 | 全键盘流程、读屏、完整对比度审计、生产性能及大数据实测未完成 |

恢复联调后继续以实际事件、评分和产物完成“发现异常→查看执行→理解评分→定位证据→比较迭代”。待上述缺口补齐，再进行完整复查和不同任务的交叉复查，满足门槛后关闭整体品质验收。

## shadcn 审美升级第一批

本批采用 shadcn Base UI 与 Tailwind CSS 4，完成公共控件、全局导航、未连接首页和实验列表改造。目标是减少重复分区和装饰性信息，统一控件尺寸与交互。目录、实验详情、执行审阅、结果对比和业务表单内部仍需后续逐页迁移；公共组件的更新已作用于这些页面。

### 本批验证

- `npm --prefix frontend run lint`、`format:check`、`typecheck`、`build` 和 `git diff --check` 通过；没有新增或修改测试文件、用例、fixtures、mocks 或自动化 snapshots。
- 使用已有 Eyes UI Review 项目的只读令牌，读取原有两条排队实验。当前服务的迁移版本为 `0001_control_plane`；本批没有修改业务数据、迁移数据库或运行 Scheduler / Runner。
- 实际操作当前页新旧排序、标准/紧凑密度、筛选无结果与清除，以及搜索后进入详情再返回。URL 中的搜索、排序、密度保留；标准与紧凑行高实际测得 56/40px。
- 检查 390、768、1024、1440px；页面宽度未超过视口，手机表格在内部横向滚动。桌面侧栏收起、手机抽屉、Escape 焦点恢复、快速导航搜索与跳转正常。
- 打开创建实验表单而未提交；在 390×700 下滚动到末尾，标题和取消/提交区保持可见，背景禁止滚动。Escape 关闭后焦点回到创建入口。
- 提交无效连接令牌显示 401 对应提示；关闭后原有有效连接仍可读取实验。Safari 补查未连接页、连接弹窗初始焦点与空令牌禁用、Escape 关闭，以及快速导航搜索“测试集”并回车跳转。
- 主浏览器本批最终 warn/error 记录为空。构建主 JS 为 358.68 kB / gzip 115.46 kB，共用组件块为 126.52 kB / gzip 45.09 kB；未进行实际性能测量。

首次配置目录为空、真实 API 加载失败、复杂执行/评分数据及所有页面的完整键盘/读屏流程尚未在本批运行验证。新增空状态与加载分支有源码及构建证据，未以虚构数据补齐运行证据。当前结果为第一批界面交付，整体品质门槛仍待后续逐页迁移与真实任务验收。

### 审查修复

- 侧栏的 `⌘ B / Ctrl B` 在弹窗、输入控件或输入法组合期间跳过，并尊重已处理的键盘事件。在 390px 视口实际打开创建实验并聚焦超时输入框，两种快捷键均未打开导航，焦点保留；列表搜索框内也未触发导航。主内容聚焦时快捷键仍可打开导航。
- Table 提供滚动容器属性入口，实验列表将焦点和可访问名称移到实际 `overflow-x:auto` 的元素。390px 下实际滚动容器宽 356px、内容宽约 713px；聚焦后按右方向键，`scrollLeft` 从 0 增加到 40px。
- ErrorNotice 的详情恢复 `max-height:260px` 和 `overflow:auto`，并可通过键盘聚焦。使用只读项目请求无效 UUID 路径，展开真实 API 的 422 校验详情，浏览器确认计算样式和焦点入口；本次详情高度为 186px，未进行大量 JSONL 错误的滚动验收。

修复后 ESLint、Prettier、生产构建（含 TypeScript）与 `git diff --check` 通过。没有新增或修改测试，也没有写入业务数据。
